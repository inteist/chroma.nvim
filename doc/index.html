Overview & Core Features

Chroma.nvim is an interactive color picker written entirely in Lua. Originally designed for custom configurations, it was extracted into a standalone plugin to provide a rich UI experience with zero runtime dependency bloat.

  • Interactive RGB/HSL/Alpha Field: Navigate a 60x12 saturation-value grid and adjust hue, saturation, lightness, red, green, blue, and alpha sliders with real-time updates.
  • Smart Target Detection: Open the picker pre-seeded with the color literal directly under your cursor or visual selection (supports CSS hex, rgb, rgba, hsl, hsla, hsv, and standard names).
  • Dual-Pane Palette & Recents Manager: Browse, edit labels inline, and select colors from saved palettes or recents. Left/right panes are bound dynamically with cursor and scroll linkages.
  • Live Editor Replacements: Highlights and replaces code color literals in the source buffer in real-time as you tweak values in the floating window.

Install via lazy.nvim. Use the opts block to customize the persistent store. 

{
  "inteist/chroma.nvim",
  opts = {
    store = {
      max_recents = 40, -- limit of recently selected colors saved
    },
  },
}

Ergonomic commands mirror keymaps for usability in scripts and command autocomplete:

Command Description
:ColorPicker [color] Open Chroma, optionally seeded with a color literal.
:ColorPickerCursor Open picker for the color under the cursor or selection.
:ColorPickerInput Prompt for a color string, then open the picker.
:ColorPickerPalettes Open the saved color palettes manager.
:ColorPickerRecents Open recently used colors.
:ColorPickerCopy [fmt] Copy color under cursor/selection in a specific format.

Lua modules export complete configurations and control handles:

local chroma = require("chroma")

-- Initialize configurations
chroma.setup({ store = { max_recents = 40 } })

-- Lua functions
chroma.open()
chroma.open({ value = "#ff00ff" })
chroma.open_under_cursor({ selection = false })
chroma.copy_under_cursor({ format = "hex" })
chroma.palettes()

Codebase Architecture

The plugin's modules are isolated and self-contained, using standard Neovim API namespaces without relying on general-purpose wrapper frameworks.

init.lua
Entry point. Registers ergonomic user commands like :ColorPicker and exposes public Lua APIs. Handles plugin lifecycle configuration setup.
state.lua
Implements the central state machine. Scans code lines beneath the cursor or visually selected targets to parse color literal formats.
color.lua
Color math engine. Parses hex, rgb, hsl, hsv and names. Translates between representations and exports normalized channel bounds.
render.lua
Generates the text buffers, colors the grid, positions selection cursor markers, builds layouts, and flushes changes to the Neovim buffer.
palette.lua
Manages saved palettes. Configures scroll-synchronized dual-pane split windows for editable item lists and inline label buffers.
window.lua
Floating window manager. Creates centered panels, sets backdrop window overlays, configures local keymaps, and populates popup help screens.
store.lua
Disk persistence layer. Loads and serializes user color palettes and recents history list in a standardized JSON file format.
geometry.lua
Helper library resolving dimensions. Maps pixel coordinate coordinates to HSL channel values for sliders and discrete hue angles.
