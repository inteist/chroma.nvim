SETUP                                                              *chroma-setup*

Chroma requires Neovim 0.10 or newer and has no runtime plugin dependencies.

With lazy.nvim: >lua

  {
    "max/chroma.nvim",
    opts = {
      store = { max_recents = 40 },
    },
  }
<

For local development: >lua

  {
    "chroma.nvim",
    dir = vim.fn.expand("~/Projects/chroma.nvim"),
    opts = {},
  }
<

===============================================================================
COMMANDS                                                        *chroma-commands*

                                                        *:ColorPicker*
:ColorPicker [color]
    Open Chroma, optionally seeded with a color value. Supported values include
    #rrggbb, #rrggbbaa, 0xrrggbb, 0xaarrggbb, rgb(), rgba(), argb(),
    RGBA tuples such as (255, 255, 255, 0.8) and (217, 217, 217, 1),
    ARGB tuples such as (0.3, 255, 255, 255) and (0, 217, 217, 217),
    hsl(), hsla(), hsv(), and common CSS color names.

                                                        *:ColorPickerCursor*
:ColorPickerCursor
    Open Chroma for the color under cursor or visual selection.

                                                        *:ColorPickerInput*
:ColorPickerInput
    Prompt for a color value, then open Chroma.

                                                        *:ColorPickerPalettes*
:ColorPickerPalettes
    Open saved color palettes.

                                                        *:ColorPickerRecents*
:ColorPickerRecents
    Open recent colors.

                                                        *:ColorPickerCopy*
:ColorPickerCopy [format]
    Copy the color under cursor or visual selection, optionally converted to a
    format. Built-in formats: hex, hexa, rgb0x, argb0x, rgb, rgba, argb,
    rgba_tuple, argb_tuple, hsl, hsla, hsv.

===============================================================================
LUA API                                                            *chroma-api*

>lua
  local chroma = require("chroma")

  chroma.setup({ store = { max_recents = 40 } })
  chroma.open()
  chroma.open({ value = "#ff00ff" })
  chroma.open_under_cursor({ selection = false })
  chroma.copy_under_cursor({ format = "hex" })
  chroma.palettes()
<
